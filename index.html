Inline

**bold** *italic* `code` ~~struck~~Always shown formatted. Select formatted text and press its shortcut again to remove the formatting. View › Source shows the raw markdown
[text](url)Link. Ctrl+click opens it, Ctrl+K on it edits the address
[[Other note]]Link to another tab by name. Ctrl+click opens or creates it. Notes that link here are listed at the bottom
@3/5 @Mar 5 @fri @tomorrowDue date, in almost any format. It is completed when you type a space after it, the current year is assumed, and it shows as @Today, @Tomorrow or @Thu 3/5. Click the date to pick another one or remove it
#tagTag. Ctrl+click a tag to filter by it. A tag on a heading or a parent item applies to everything under it
! !! !!!Priority, as a word on its own anywhere in the line. Shown as a chip; the filter and Edit › Sort section know about it. Ctrl+Shift+↑ / ↓ raises or lowers it
Typing # [[ or @Suggests tags, note names and dates as you type: after @, the dates used in your notes and the next two weeks, narrowed by what you type (@fri, @2026-09, @tom). ↑ ↓ choose, Enter or Tab accepts, Esc dismisses
Hover a [[link]]Previews the first lines of that note

Editing

EnterNew line, continuing the list. On an empty item, ends the list. At the start of a heading, moves the heading down and leaves an empty heading above it
Ctrl+Enter / Ctrl+Shift+EnterNew line below / above, without splitting the current one
Tab / Shift+TabIndent / outdent the selected lines
Backspace at line startRemove the checkbox (a bullet goes with it), then the bullet or number, then outdent, then join with the line above
Ctrl+Backspace / DeleteDelete the word before / after the caret. With Shift, delete to the start / end of the line
Ctrl+DDuplicate the selected lines (a collapsed line takes what is folded under it along)
Alt+↑ / ↓Move the line (with anything nested under it). Lines can also be dragged by the ⠿ handle
Edit › Sort sectionSorts the items around the caret by date, by priority, open items first, or A to Z. On a list item it sorts that list; elsewhere it sorts everything under the nearest heading. Nested lines move with their parent
Ctrl+SpaceCheck / uncheck the selected lines, adding a checkbox if there is none
Ctrl+Shift+SpaceAdd or remove the checkbox itself; a number stays, a bullet goes with the box. Alt+click the box in the margin also removes it
Ctrl+Shift+DDue date: adds today, then cycles today, tomorrow, next week
Alt+← / →Collapse / expand the current section or list. Ctrl+. toggles it, Ctrl+Shift+. does everything. A collapsed heading shows how many lines it hides; a heading over checkboxes shows how much is done
Ctrl+B I E KBold, italic, code, link. Ctrl+Shift+X strikethrough
Shift+arrows, PgUp/PgDnSelect text, across lines too. Ctrl+Home / End go to the first / last line
Ctrl+Z / YUndo / redo

Files and view

Ctrl+Shift+PCommand palette: type part of any menu action, tab name or heading and press Enter
Ctrl+Shift+AAgenda: every open item with a date, from every tab, grouped by day. Check items off there or click one to jump to it
Alt+F E VOpen a menu. Arrow keys move, the underlined letter or Enter chooses, → opens a submenu, Esc closes
Right-clickMenu of the common line actions. Shift+right-click keeps the browser's own menu, with its spelling suggestions
Ctrl+S / Ctrl+Shift+SSave / save as. Opened files are remembered, so Save writes straight back
File › Open folder…Choose a notes folder. Its files are listed in the File menu, new notes save into it without a dialog, and [[links]] open or create files there
Ctrl+O / Ctrl+POpen one or more files / print or save as PDF. Files can also be dropped onto the page
File › WorkspaceOpen a whole folder as tabs (subfolders included), or save the open files as a named workspace and reopen them together later, from one folder or several. Opening a workspace replaces the tabs that have nothing unsaved; tabs with changes stay. A folder dropped onto the page opens as a workspace too. In a folder workspace a new tab is a file in the folder at once, edits are saved as you type, and notes added, changed or removed in the folder by other programs appear in the tabs (Settings can turn either off)
Alt+N / Alt+WNew tab / close tab. Alt+1…9 switches. Double-click a tab or the title to rename. A file is renamed on disk too; PowerNotes asks for access to its folder the first time
Ctrl+Tab / Ctrl+Shift+TabNext / previous tab, where the browser lets a page have that key. Alt+PgDn / PgUp always works
Ctrl+Shift+PgUp / PgDnMove the tab left / right (Alt+Shift+PgUp / PgDn too). Tabs can also be dragged into place
Ctrl+F / Ctrl+HFind / replace
Ctrl+Shift+FFilter by open or done, due date and tags. Parents keeps the headings and parent items of matches, Children keeps what is nested under them, Dim fades the rest instead of hiding it. View › Today is a preset for open items due today or earlier
Ctrl+Shift+OOutline sidebar
Ctrl+= − 0 or Ctrl+wheelZoom in, out, reset
F1 or Ctrl+/This help, also under File › Help

Settings

In a folder workspace a new tab is a file in the folder from the start, and notes added, changed or removed in the folder by other programs show up in the tabs a few seconds later. With saving as you type, edits reach the file about a second after you pause; otherwise Ctrl+S writes them.

Spelling marks are drawn by the browser, not by PowerNotes, and only after you type. Click at the end of the test box and type a space: if the misspelled words get no wavy underline there either, spell checking is off in the browser. Chrome: Settings › Languages › Spell check. Edge: Settings › Languages › Check spelling as you type. On Windows the basic checker also needs the language's typing pack, under Windows Settings › Time & language › Language & region › (your language) › Language options.
